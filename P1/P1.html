P P1. Regresión¶

Objetivo del proyecto:

El objetivo principal es predecir la longitud total de los tlacuaches (totlngth) a partir de variables morfométricas y demográficas, como edad, sexo, tamaño de cola, sitio de captura, entre otras. Se busca identificar cuáles de estas variables tienen mayor poder predictivo y caracterizar la relación entre ellas y la longitud total, utilizando modelos de regresión lineal y no lineal. Esto permitirá entender mejor los factores que influyen en el tamaño de los tlacuaches y evaluar la capacidad de los modelos para realizar predicciones precisas y generalizables.

Datos obtenidos de https://www.kaggle.com/datasets/abrambeyer/openintro-possum

  • case: caso de observación
  • site: El sitio donde el tlacuache fue atrapado.
  • Pop: Población, Vic (Victoria) o other (New South Wales o Queensland).
  • sex: m (macho) o f (hembra).
  • age: Edad.
  • hdlngth: Longitud de cabeza en mm.
  • skullw: Ancho de cráneo en mm.
  • totlngth: Longitud total en cm (variable respuesta de interés).
  • taill: Tamaño de cola en cm.
  • footlgth: Longitud de pies en mm.
  • earconch: Longitud de caracola de la oreja en mm.
  • eye: Distancia del canto medial al canto lateral del ojo derecho en mm.
  • chest: Circunferencia del pecho en cm.
  • belly: Circunferencia del vientre en cm.

Esto ayuda a evitar el sobreajuste y mejora la interpretabilidad del modelo, asegurando que solo las variables más relevantes sean utilizadas.

from sklearn.linear_model import LinearRegression
import numpy as np

def adjusted_r2_score(model, X, y):
    r2 = model.score(X, y)
    n = X.shape[0]
    p = X.shape[1]
    return 1 - (1 - r2) * (n - 1) / (n - p - 1)

features = list(X.columns)
current_X = X.copy()
best_adj_r2 = -np.inf
improvement = True

while improvement and len(features) > 1:
    scores = []
    for feature in features:
        temp_features = [f for f in features if f != feature]
        model = LinearRegression().fit(current_X[temp_features], y)
        adj_r2 = adjusted_r2_score(model, current_X[temp_features], y)
        scores.append((adj_r2, feature))
    scores.sort(reverse=True)
    best_score, feature_to_remove = scores[0]
    if best_score > best_adj_r2:
        best_adj_r2 = best_score
        features.remove(feature_to_remove)
        print(f"Atributo eliminado: {feature_to_remove}, R^2 ajustado: {best_score:.4f}")
    else:
        improvement = False

print("Características finales seleccionadas:", features)

Un coeficiente es significativo si su valor absoluto es considerable y consistente con el contexto del problema, y si el modelo mejora al incluirlo. Por ejemplo, los coeficientes de (0.47) y (1.30) son relativamente altos, lo que indica una fuerte asociación positiva con la longitud total.

Para afirmar estadísticamente la significancia, sería necesario calcular los intervalos de confianza o los valores p, pero el proceso de selección y el tamaño de los coeficientes ya nos dan una buena indicación de su relevancia en el modelo.

from sklearn.model_selection import train_test_split
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import Pipeline

df = df[features + ['totlngth']]

X = df.drop(columns=['totlngth'])
y = df['totlngth']

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=100)

# Entrenar modelo lineal con datos de entrenamiento
linear_model = LinearRegression()
linear_model.fit(X_train, y_train)
print("Coeficientes del modelo lineal:", linear_model.coef_)
print("Intercepto:", linear_model.intercept_)
print("R^2 del modelo lineal (train):", linear_model.score(X_train, y_train))
print("R^2 del modelo lineal (test):", linear_model.score(X_test, y_test))

# Modelo de regresión polinomial (grado 2)
poly_model = Pipeline([
    ('polynomialfeatures', PolynomialFeatures(degree=2, include_bias=False)),
    ('linearregression', LinearRegression())
])
poly_model.fit(X_train, y_train)
print("R^2 del modelo polinomial (grado 2, train):", poly_model.score(X_train, y_train))
print("R^2 del modelo polinomial (grado 2, test):", poly_model.score(X_test, y_test))

# Graficar valores reales vs predichos en el set de prueba para ambos modelos
y_test_pred_linear = linear_model.predict(X_test)
y_test_pred_poly = poly_model.predict(X_test)

plt.figure(figsize=(8, 5))
plt.scatter(y_test, y_test_pred_linear, label='Lineal', color='blue', alpha=0.7)

plt.title('Valores reales vs predichos (test)')

El MSE de train y test nos indica el promedio de las diferencias al cuadrado entre los valores reales y los predichos. Un valor más bajo indica mejores predicciones. El modelo lineal tiene un MSE de test 4.85 mientras que el modelo polinomial tiene un MSE de test mucho mayor (35.61), indicando que el modelo lineal generaliza mejor a datos no vistos.
